# Adopters

This file lists organizations that **use this project in production** (or at significant scale).  
It is **non-exhaustive** and is maintained on a best-effort basis.

## How to add your organization

Please open a pull request that adds your organization to the list below.

**Guidelines (recommended):**
- Keep entries in **alphabetical order**.
- Use the organization’s **official name**.
- Optionally include a **contact** (GitHub handle)
- Optionally include a **public reference** (blog post, case study, talk, GitHub repo, etc.).
- Only add your organization if they are comfortable being publicly listed as an adopter.
